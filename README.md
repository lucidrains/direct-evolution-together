# direct-evolution-together (wip)

A small application that allows for any person to form a team or collaboration with crowds online to do [directed evolution](https://en.wikipedia.org/wiki/Directed_evolution) on neural networks

A test site is live <a href="https://thispersondoesnotexist.com/evolution">here</a>

## install

```bash
$ pip install direct-evolution-together
```

requires [nim](https://nim-lang.org/install.html)

## usage

```bash
$ direct-evolution-together
```
